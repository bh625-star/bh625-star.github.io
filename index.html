Real-Time Payments Fraud Analysis

Data Analytics · Internship

During my internship at a payments clearing company, I analyzed hundreds of millions of Real-Time Payments (RTP) transactions to find patterns that separate fraudulent accounts from normal activity.

  • Built SQL detection pipelines for fan-in/fan-out flows, payment velocity, mule-account behavior, and Request-for-Payment abuse.
  • Applied statistical outlier methods (percentiles, z-scores, IQR) to flag unusual accounts and amounts.
  • Found that confirmed fraud accounts often received additional payments from other senders within minutes of the flagged payment, and that funds tended to leave on other payment rails rather than RTP.
  • Optimized queries for a partitioned, read-only database using partition pruning and window functions instead of self-joins.

Tools: PostgreSQL, SQL window functions, EXPLAIN / query planning

Code and data are confidential to the employer, so no public repository is available.
